Road safety and accident detection have become a paramount necessity of today, as vehicular density keeps increasing. 
To address these issues, we propose to design and develop an Accident Detection System using
the ESP8266 Wi-Fi microcontroller, to provide real-time monitoring, immediate alerts, and remote
accessibility to enhance emergency response to road accidents.

The scope of the Accident Detection System encompasses the following:

1. Real-Time Accident Detection: The system continuously monitors vehicle motion and impact using
sensors (accelerometer/gyroscope - MPU6050) to detect sudden changes indicative of an accident.

2. Immediate Alert Generation: Upon detection, the system instantly sends alert notifications via Wi-Fi
using the ESP8266 module to notify emergency contacts or services.

3. Location Accessibility: The system can be integrated with a GPS module to transmit the location of
the accident to responders, enabling faster and more precise emergency response.

4. Remote Monitoring: The solution supports IoT-based remote access via ThingSpeak, allowing emer-
gency services or designated contacts to receive real-time accident alerts and data through an online
dashboard.

5. Standalone Embedded System: The system is designed as a compact, low-power embedded solution
suitable for installation in vehicles.

Limitations: The current scope does not include integration with national emergency service databases
or cellular (GSM) communication; instead, it relies on available Wi-Fi connectivity.

Programmed on the Arduino IDE and simulated on the Wokwi simulator.
